# Frontend Wizard Module

## Purpose
Implements Module 4 by rendering the first-pass 5-step application experience.

## Included in this iteration
- route: `/applications/[applicationId]`
- draft fetch on load
- step shell for personal, passport, travel, documents, and review
- manual draft save
- saved-step resume behavior
- payment area hidden from the applicant flow

## Notes
- Step 4 currently uses document readiness placeholders instead of real uploads
- validation, autosave, OCR, and true upload handling will be layered in later modules
