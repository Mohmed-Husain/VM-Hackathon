# Frontend Profile Prefill

## Purpose
Implements Module 7 by letting applicants reuse saved personal and passport details.

## Current behavior
- loads the saved applicant profile when the wizard opens
- shows a `Use my saved profile data` action in Steps 1 and 2
- lets the applicant save current Step 1 and Step 2 details back to the profile
- merges profile data into the current draft without leaving the wizard
