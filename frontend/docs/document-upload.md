# Frontend Document Upload

## Purpose
Implements Module 8 by replacing the document placeholders with live upload cards.

## Current behavior
- renders one upload card for each required document type
- supports click-to-upload plus drag and drop
- shows uploaded filename, size, and a link to the stored file
- allows replace and remove actions
- refreshes application document readiness after each upload or delete

## Notes
- client-side compression and OCR are still separate later modules
- payment remains hidden from the applicant flow
