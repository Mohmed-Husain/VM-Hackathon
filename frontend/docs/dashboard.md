# Frontend Dashboard Module

## Purpose
Implements Module 3 by showing the authenticated applicant's applications and the create/resume entry points.

## Included in this iteration
- backend-synced application list on `/dashboard`
- status, progress, and current step display
- seeded draft resume button
- new application creation cards for the simplified MVP visa categories

## Notes
- the primary seeded demo user shows one resumable in-progress draft by default
- the second seeded demo user remains a clean-slate onboarding path
