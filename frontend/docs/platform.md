# Frontend Platform Module

## Scope
Module 1 establishes the Next.js application shell for the MVP.

## Included in this iteration
- Next.js App Router project structure
- global layout and baseline visual system
- environment-ready API integration layer
- reusable session persistence helpers
- a protected route shell for authenticated pages

## Notes
- The frontend expects the API at `http://localhost:8000` by default.
- If needed, set `NEXT_PUBLIC_API_BASE_URL` for a different backend origin.
